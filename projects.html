Sentinel Rate Limiter

Redis, race conditions and the tiny thrill of making one request too many.

A distributed rate limiter built on Redis sorted sets, where a single atomic Lua script does evict, count and add in one round trip, so two concurrent requests can’t both see the same old count. A multi-step LangGraph agent (gather context, LLM risk assessment, hard policy guardrail) sits on top with an offline fallback, tested in CI without an LLM key. Includes Kubernetes manifests and a CI coverage gate.

MerchantLens

Settlement reconciliation, analytics and chargeback lifecycle for payments.

A PostgreSQL project where the database itself enforces the rules: a trigger-based chargeback state machine (RECEIVED → UNDER_REVIEW → … → ARBITRATION), a database-written audit log on financial tables, and a rolling 7-day chargeback-ratio alert. A JWT-secured Spring Boot API fronts it with DTOs, an Apex class syncs disputes to Salesforce Cases, and CI runs secret scan, SAST, DB validation and tests. All data is synthetic.

Authswitch: Transaction Anomaly Notifier

Real-time fraud scoring with async alerts, built with payments infrastructure in mind.

A rule engine combines five signals (z-score, high value, velocity, location, device) into a 0–100 risk score with a reason string and recommendation. Supports single and batch scoring (100-transaction cap), PostgreSQL audit logs, non-blocking email and Slack alerts through Celery and Redis, Docker Compose, CI, and an AWS Lambda path.
